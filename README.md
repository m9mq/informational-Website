## 🌟 المميزات (Features)

- **🎨 تصميم Glassmorphism داكن**: خلفية تفاعلية مع أنيميشن نيون وجزيئات متلألئة (Floating Particles).
- **🎵 مشغل Spotify تفاعلي**: عرض قائمة التشغيل أو الأغنية المباشرة عبر Spotify Embed Widget.
- **⚡ عنوان صفحة حركي (Dynamic Title)**: تأثير كتابة واسم الصفحة يظهر بشكل Typing Animation في شريط المتصفح.
- **📱 متوافق مع كافة الشاشات (Fully Responsive)**: يعمل بسلاسة على كافة الهواتف الذكية والأجهزة اللوحية والحواسيب.
- **🔒 أمان عالٍ وسرعة فائقة**: مجهّز بـ Security Meta Tags وحجم خفيف جداً بدون مكتبات ثقيلة (Pure HTML/CSS/JS).
